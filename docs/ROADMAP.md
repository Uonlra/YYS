# 项目路线图

目标是让新用户能够独立安装、验证和运行，让贡献者能够稳定复现行为并安全修改执行器。下列内容是工作方向，不是已实现功能或发布日期承诺。

## 已具备的基础

- Windows 场景执行、模板匹配、有限重试和恢复。
- 点击白名单、冷却、预算、紧急停止与 dry-run。
- 轮转日志、失败截图、原子状态快照和场景编辑器。
- 配置初始化、独立配置校验、CLI 参数互斥及 GUI 试运行传递。
- Windows 多版本 CI、模拟画面回归测试和贡献指引。

## 发布前优先项

- 作者选择许可证，核实模板图片来源及可分发范围。
- 整理标准 Python 包布局和安装后命令入口，验证 wheel 在仓库外可独立使用。
- 提供可复现的 Windows 发布包，验证干净机器上的安装、启动和升级。
- 区分个人配置与随包示例，建立配置版本与迁移约定。

## 用户体验

- GUI 内编辑全局窗口、安全和识别设置，并展示当前 dry-run 状态。
- 运行前展示目标窗口、点击预算和识别区域预览。
- 增加可导出的诊断报告，并在导出前提供截图与路径检查。
- 精简主 README，将高级状态确认、恢复和性能说明迁入专题文档。

## 质量与维护

- 增加真实窗口的可控集成测试，覆盖分辨率、缩放和窗口关闭。
- 为安装包构建、配置兼容和示例文件增加持续验证。
- 建立版本变更记录与发布检查流程，再按实际需求扩展执行器。
